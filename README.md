# 💰 ISK Tracker — EVE Online Financial Dashboard

> Professional financial audit tool for EVE Online pilots. Track your ISK, analyze income & expenses, and export reports.

**[🚀 Live Demo](https://kingsyah.github.io/ISK-Tracker/)**

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 📊 | **Smart Dashboard** | KPI cards, balance history, daily net flow |
| 🍩 | **EVE-style Overview** | Donut chart income breakdown (like in-game wallet) |
| 🔍 | **Transaction Ledger** | Search, filter, sort & pagination |
| 📈 | **Category Analysis** | Per-category breakdown with visual bars |
| 👆 | **Category Detail** | Click any category to see its transactions |
| 🌗 | **Dark / Light Theme** | Toggle with saved preference |
| 📄 | **PDF Export** | Multi-page report with charts, tables & stats |
| 🔒 | **100% Client-Side** | No server. No tracking. Your data stays yours |

---

## 🚀 Quick Start

```
1. Open → https://kingsyah.github.io/ISK-Tracker/
2. Click Import 📥
3. Copy from EVE Online → My Wallet → Journal
4. Paste → Done ✓
```

No install. No signup. Just open and use.
